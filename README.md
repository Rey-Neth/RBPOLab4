# Лабораторная 4

Spring Security добавлен к конструктору опросов из лабораторной №3. Java 17+, PostgreSQL.

Приложение: `http://localhost:8080`.

- **Basic Auth** — логин и пароль в каждом защищённом запросе.
- **BCrypt** — в БД лежит хеш, а не пароль.
- **USER** — свои опросы и ответы; **ADMIN** — любые данные. Чужой черновик скрыт.
- Регистрация всегда даёт USER. Пароль: от 12 символов, до 72 байт, большая/маленькая латинские буквы, цифра, символ. Логин уникален; `enabled=false` запрещает вход.
- **401** — ошибка входа, **403** — нет прав или CSRF, **400** — нарушено бизнес-правило, **409** — конфликт данных.

## Проверка

Учебные аккаунты: `admin / TestAdmin123!` и `respondent / TestAccount123!`. Созданные коллекцией записи удаляются в конце.

Код: `SecurityConfig` — вход и защита, `AccessService` — владелец данных, `UserService` — регистрация, `ApiController` — адреса API.
